# Expense & Budget Visualizer — Project Steering

## Project Overview
This project is built as part of the CodingCamp assignment.
It is a mobile-friendly Expense & Budget Visualizer web app.

## Tech Stack
- HTML5 (structure)
- CSS3 (styling, single file: css/style.css)
- Vanilla JavaScript (no frameworks, single file: js/app.js)
- Chart.js via CDN for pie chart
- Browser LocalStorage for data persistence

## Folder Rules
- Only 1 CSS file inside `css/`
- Only 1 JavaScript file inside `js/`

## Features Implemented
### MVP
- Input form with validation (Item Name, Amount, Category)
- Scrollable transaction list with delete functionality
- Auto-updating total balance
- Pie chart (Chart.js) for spending by category

### Optional Challenges (3 of 5)
1. Allow users to add custom categories
2. Sort transactions by amount or category
3. Highlight spending over a set limit
