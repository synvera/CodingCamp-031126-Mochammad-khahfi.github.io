# Expense & Budget Visualizer

A mobile-friendly web app to track daily spending, built with HTML, CSS, and Vanilla JavaScript.

## Features

### Required (MVP)
- **Input Form** — Add transactions with Item Name, Amount, and Category (Food, Transport, Fun)
- **Transaction List** — Scrollable list with item name, amount, category badge, and delete button
- **Total Balance** — Updates automatically when transactions are added or removed
- **Pie Chart** — Spending distribution by category using Chart.js, updates in real time

### Optional Challenges
1. **Custom Categories** — Add your own spending categories beyond the defaults
2. **Sort Transactions** — Sort by latest, oldest, amount (high/low), or category
3. **Highlight Spending Over Limit** — Set a spending limit; items exceeding it are highlighted

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)
- [Chart.js](https://www.chartjs.org/) (CDN)
- Browser LocalStorage for data persistence
